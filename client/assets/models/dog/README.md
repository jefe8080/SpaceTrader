# Hund

Low-Poly-Asset im Stil des Questhauses. GLB enthält nur das Modell mit eingebetteten PBR-Materialien. Die Blender-Datei enthält zusätzlich eine separate Preview_Stage.

Ein statisches Mesh, 680 Dreiecke. Ursprung auf Bodenhöhe, Maße in Metern, GLB: Y oben, Front +Z. Keine externen Texturen.

Noch nicht in den 2D-Canvas-Renderer integriert. Erzeugung über generate.py in Blender; vorhandene Modelle werden nicht überschrieben.
